# 写真の出典一覧

アプリで使う写真の出典とライセンス。写真を足したら、同じコミットでこの表に行を足す。

- 置き場所: `public/images/`（地域は `public/images/areas/`、スポットは `public/images/spots/`。#30 の案と同じ方針）
- DB の `image_path` には `public/` からのパス（例: `/images/areas/hakuba.jpg`）を書く。写真がない間は `null`（表示側でプレースホルダーを出す）
- 使えるのは、自分たちで撮影したものか、ライセンスが明確なものだけ（docs/spec.md データ-1）。参考 PoC の写真は使わない
- 1枚あたり長辺 1200px・300KB 以下を目安にする

## スポット（spots、#30・#58）

北アルプス山麓の5地域のスポット（#30）の写真を #67 で用意した。Wikimedia Commons で、ライセンスが CC BY・CC BY-SA・CC0・パブリックドメインのものだけを使い、写っているのがそのスポットだと、写真の説明・撮影地・画像そのもので確かめた（2026-09-25）。Commons にないものは、Flickr で撮影者が CC BY を付けた写真を Openverse で探して使った（NC・ND は使わない。題名・タグ・位置情報でスポットを確かめた。2026-09-26）。長辺を1200px以下に縮小し、300KB 以下に圧縮して `public/images/spots/` に置いた（パスの番号は `spots.id` の末尾2桁と同じ）。

- 撮影者・ライセンス・元の写真の題名は、アプリの「写真の出典」ページ（`/credits`、フッターからリンク）に出す（CC BY・CC BY-SA は、題名が付いていればその表示も求める）。題名は、Flickr は写真のページの題名（2026-09-26 に4件とも確かめた）、Commons はファイルページの名前（`File:` を除き `_` を空白にしたもの）を書く。元のデータは `lib/photo-credits.ts`。写真を足すときは、ここと `lib/photo-credits.ts`・`supabase/seed.sql` の `image_path` を同じコミットで直す
- 見つからないスポットは `image_path` を `null` のまま（表示側はカテゴリのイラスト）にし、理由を下の表に書いた
- スポットの事実の出典は docs/spot-sources.md
- 全国の7地域のスポット（#58）の写真は #132 で同じ探し方で用意した（2026-09-26）。42件中28件が Commons で見つかり、残り14件は探した語と結果を表に書いた
- 見つからなかった32件は、#146 で探す範囲を広げ（下の「探す範囲を広げた結果」）、3件が見つかった。残りは AI で生成したイメージ画像を付け、画面に「イメージ（AI で生成）」と出す（AI の画像は `public/images/spots/ai/` に置く）

### 探す範囲を広げた結果（#146、2026-09-26）

Commons・Openverse で見つからなかった32件について、自治体・観光協会・県の写真素材集、自治体のオープンデータ（観光施設一覧などの画像の列）、政府標準利用規約・公共データ利用規約（PDL1.0）で公開された写真を探した。規約の条文を読み、**申請がいらず、商用で使えて、縮小・圧縮ができ、用途が限られていない**ものだけを使った。お店の公式サイト・Google マップの写真は使わない。

- 見つかったのは3件（東川町のキトウシの森・大雪旭岳源水・北の住まい設計社）。どれも北海道上川総合振興局の写真集「[北海道の風景～VIEW OF KAMIKAWA～](https://www.kamikawa.pref.hokkaido.lg.jp/ts/tss/album/view_of_kamikawa_top.html)」の写真
  - 規約: トップページに「北海道上川総合振興局職員が撮影した風景…の画像を公開」「画像の利用は、個人、企業に関わらず全て無料です。ホームページ、ブログ、はがき、カレンダーなど使い方は自由です」。各ページに cc-by のアイコンがあり、[サイトポリシー](https://www.kamikawa.pref.hokkaido.lg.jp/site-info/sitepolicy.html)に「特に記載の無い限り、すべてのページを Creative Commons の表示CC-BY とします」（リンク先は CC BY 4.0）。写真は職員の撮影で、ページに第三者の撮影者・提供者の表記はない
  - 使う条件: CC BY 4.0（商用・加工ができる）。クレジットは「北海道上川総合振興局」「北海道の風景～VIEW OF KAMIKAWA～」・題名・ライセンス・元のページを `/credits` に出し、縮小・圧縮したことも書く
  - 「ご利用規約」として、使ったあとに画像の番号・使い方などを問い合わせフォームで知らせてほしいというお願いがある（許可の手続きではない）。持ち主が知らせる（番号: 133087・133653・132066）
- 残りの29件は見つからなかった。#158 で AI で生成したイメージ画像を付けた（作り方・決まり・規約の確認は下の「AI で生成したイメージ画像」。プロンプトの要旨は `lib/photo-credits.ts` の `AI_IMAGE_CREDITS`）

### AI で生成したイメージ画像（#158、2026-09-26）

上の表で「AI の画像（#158）」とした29件は、許可のいらない写真が見つからなかったので、AI で生成したイメージ画像を付けた。画面（カード・詳細・経路のカード）では画像に「イメージ（AI で生成）」と添え、`/credits` にモデルとプロンプトの要旨を出す（元のデータは `lib/photo-credits.ts` の `AI_IMAGE_CREDITS`）。

- 作り方: Codex CLI（ChatGPT のアカウントでログイン、API キーは使わない）の組み込みの画像生成（`image_gen`）で1スポット1枚作り、1200×900・300KB 以下の JPEG にして `public/images/spots/ai/` に置いた（ファイル名は写真と同じく `spots.id` の末尾2桁）
- 絵柄: ほかのスポットの写真（Commons など）と並んでも浮かないよう、写真調にそろえた。一般の旅行者のスナップ写真の質感（目の高さ・35mm 前後・手前から奥までピントが合う）、自然な昼の光、彩度とコントラストはひかえめ、横長 4:3
- 誤解を避ける決まり（全部のプロンプトに入れた）: 文字・数字・看板の文字・ロゴ・透かしを入れない。実在の店や施設の外観・看板・特定の建物や名所の形を再現しない。人物の顔を写さない。店のスポットは建物でなく料理・品物・作業台だけを写す
- 季節は `seed.sql` の `best_time` から決めた（通年のものは初夏）
- 作った画像は1枚ずつ目で確かめ、文字・看板・人の顔が出たもの、カテゴリと合わないものは作り直した
