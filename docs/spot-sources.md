# スポットの出典

`supabase/seed.sql` のスポットについて、書いた事実をどこで確かめたかを1件ずつ残す。北アルプス山麓5地域（#30）は下の「一覧」と「スポットごとの出典」、全国のほかの地域（#58）は最後の「全国のほかの地域（#58）」。スポットを直すときは、同じコミットでこの表も直す。

## 書き方の約束

- 実在し、一般に公開・営業している場所だけを載せる。私有地・立入禁止・危険な場所（上級の登山ルートなど）・休業中の場所は載せない
- 名前・営業時期・時間・料金・行き方などの事実は、公式サイト・自治体・観光協会・運営団体のページで確かめた（2026-09-25 時点）。まとめサイトや個人のブログは出典にしない
- 確かめられなかったことは書かない（推測で埋めない）。営業時間や料金は変わるので、`description` にはなるべく入れず、入れるときは出典に載る値をそのまま使う
- `rating` と穴場度は、docs/spot-scores.md（#61）の基準で手で付けた値。事実ではなく判断なので、根拠を下の表に書く。根拠は確かめられる事実（どこに載っているか・載っていないか）で書き、現地で見ていないこと（観光客の多さなど）には「（推測）」を付ける
- `image_path` は写真を用意するまで全件 `null`（#67）。予定のパスは docs/image-credits.md

## 緯度経度の取り方

次の順で取り、スポットごとに「座標の取り方」の列に書いた。どれも公式の住所・所在地と食い違わないことを確かめている。

1. 公式ページに座標が載っていれば、その値
2. 公式の住所を[国土地理院のジオコーダー](https://msearch.gsi.go.jp/address-search/AddressSearch?q=)で引き、番地まで当たった値
3. 番地がない・番地まで当たらない場所は、OpenStreetMap の施設の位置（名前と、公式の住所・地図の範囲が合うものだけ）
4. それもない場所は、公式ページの埋め込み地図の中心（目安。数十〜数百 m ずれることがある）

地図のピンの位置として使う精度（おおむね100m 以内）を目安にしている。道案内には使わない。

全スポットの座標が、登録した地域（市町村）の行政区域の中にあることを、国土数値情報の行政区域データ（N03、2025年1月1日時点の長野県）で確かめた（2026-09-25）。

## 津和野町（#161）

試しに足す3地域（#161）の一つ。書き方の約束・座標の取り方・評価と穴場度の付け方は、上の北アルプス山麓・#58 と同じ。事実は2026-09-26に公式・自治体・観光協会のページで確かめた。

- 近い地域（80 km 以内）がないので、#58 と同じく1地域6件にした。史跡・眺め（3件）とお店・温泉（3件）をまぜた
- 全スポットの座標が、津和野町の境界（`areas.boundary`、OpenStreetMap relation 4088334）の中にあることを、DB の `geojson_contains_point()` で確かめた（2026-09-26）
- 地域の中心（`center_lat` / `center_lng`）は、ほかの地域と同じく役場の位置。津和野町役場の本庁舎（枕瀬218-18）は国土地理院のジオコーダーで番地まで当たらないので、町の公式ページ（<https://www.town.tsuwano.lg.jp/www/contents/1000000027000/index.html>）の地図の座標を使った。本庁舎は町の北東（日原）にあり、スポットのある城下町から離れているが、地図は境界に合わせて表示される（#14）
- 観光協会と公式サイトで値が違うものは、お店・施設の公式サイトの値を使った（山田竹風軒の営業時間、堀庭園の入場料）。営業時間が食い違うものは `description`・`local_tip` に書いていない
- 候補にしたが入れなかったもの: 乙女峠・マリア聖堂、殿町通り、森鷗外旧宅（6件に絞るため。史跡が多くなりすぎないよう、お店と温泉を優先した）。山本風味堂（2025年12月に閉店と観光協会が告知）
