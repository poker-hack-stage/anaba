# スポットの評価と穴場度

スポットの評価（星）と穴場度は、シードを書く人が手で付ける値として `spots` テーブルの列に持つ（docs/spec.md データ-3、#29）。訪問記録から計算はしない。

このページは、シード（`supabase/seed.sql`、#30）に値を書く人向けの基準と、アプリでの読み出し方をまとめる。

## 列

| 列                 | 型             | 範囲            | 値がないとき |
| ------------------ | -------------- | --------------- | ------------ |
| `rating`           | `numeric(2,1)` | 0〜5（小数1桁） | `null`       |
| `hidden_gem_score` | `smallint`     | 1〜5 の整数     | `null`       |

範囲外の値は DB の check 制約で拒否される。穴場度は整数で書く。`2.5` のような小数はエラーにならず四捨五入されて入る（`2.5` → 3、`0.5` → 1）。

## 評価（`rating`）の付け方

「行った人がどれくらい満足するか」を表す。有名かどうかは穴場度で表すので、評価には入れない。

- **1.0〜5.0 を 0.5 刻みで付ける**（DB は 0〜5・小数1桁を受け付けるが、手で付けるときにぶれないよう刻みをそろえる）
- 目安: 5.0 = わざわざ遠くから行く価値がある / 4.0 = 近くに来たら寄りたい / 3.0 = 悪くない / 2.0 以下 = おすすめには向かない（載せない方がよい）
- 迷ったら、Google マップなどの評価を参考に、口コミの少なさで下げすぎない
- 分からないときは `null` のままにする（表示されず、おすすめの並べ順では後ろになる）

口コミ（#51〜#53）の平均は、今はこの列に入れない。評価と口コミの関係は #56 で決める。

## 穴場度（`hidden_gem_score`）の付け方

「観光客に知られていない、地元の人の『いつもの場所』らしさ」を表す。次の3つの観点を見て、いちばん近い段階を選ぶ。

- **観光客の少なさ**: 休日に行ったとき、観光客（地元以外の人）がどれくらいいるか
- **知名度の低さ**: ガイドブック・旅行サイト・SNS にどれくらい載っているか
- **地元の人のおすすめ度**: 地元の人が「ここはいい」と人に勧める場所か

| 穴場度 | 表示       | 意味                                                                               | 例                                       |
| ------ | ---------- | ---------------------------------------------------------------------------------- | ---------------------------------------- |
| 5      | 💎💎💎💎💎 | 地元の人しか知らない。旅行サイト・SNS にほとんど出てこない。観光客はまず見かけない | 住宅街の中の小さな銭湯、看板のない喫茶店 |
| 4      | 💎💎💎💎   | 地元では知られているが、市外の人はほぼ知らない。旅行サイトに少し載っている         | 地元の人が通う定食屋、地元の人の散歩道   |
| 3      | 💎💎💎     | 地域の観光情報には載るが、全国的には知られていない。休日でも混まない               | 市の観光パンフレットに載る展望台         |
| 2      | 💎💎       | 県内では有名。旅行サイトやガイドブックに載っていて、休日は観光客が多い             | 県の観光ランキングに入る寺社             |
| 1      | 💎         | 全国的に有名な観光地。休日は混む                                                   | 誰でも名前を知っている名所               |

- 3つの観点で段階が分かれるときは、**観光客の少なさ**を優先する
- 地元の人がまったく勧めない場所は、知られていなくても穴場度を上げない（アプリに載せるかから考え直す）
- 判断がつかないときは `null` のままにする（表示されず、穴場度で並べるときは後ろになる）

## アプリでの読み出し

`spot.rating` / `spot.hidden_gem_score` を直接読まず、`lib/spots/score.ts` を通す。

| 関数                            | 返す値                                      | 使う場面                                              |
| ------------------------------- | ------------------------------------------- | ----------------------------------------------------- |
| `getRating(spot)`               | 0〜5 の数、値がない・範囲外なら `null`      | 表示（`null` なら出さない）                           |
| `formatRating(rating)`          | 「4.5」のような小数1桁の文字列              | 表示                                                  |
| `getHiddenGemScore(spot)`       | 1〜5 の整数、値がない・範囲外なら `null`    | 表示（`null` なら出さない）・Claude に渡す情報（#18） |
| `compareByRating(a, b)`         | 評価の高い順。値がないものは評価 0 より後ろ | おすすめ選定・デモの候補生成                          |
| `compareByHiddenGemScore(a, b)` | 穴場度の高い順。値がないものは後ろ          | 穴場度で並べるとき（#12・#18・#19）                   |

今これを通しているのは、情報パネルのカード（`components/spots/spot-card.tsx`）・詳細（`components/spots/spot-detail-dialog.tsx`）・おすすめ選定（`lib/spots/recommend.ts`）・デモの候補生成（`lib/planner/generate.ts`）の4か所。穴場度の表示（💎）はカード（#15）と詳細（#22）で、穴場度を使った並べ方はおすすめ選定（#12）とデモモード（#19）で足す。
